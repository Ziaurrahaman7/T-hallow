# STA/AP — USB বন্ধ হলে বোর্ড অফ / ব্যাটারি LED না জ্বলা

ফার্মওয়্যার এটা ঠিক করতে পারে না — **পাওয়ার পাথ হার্ডওয়্যার**।

## সাধারণ কারণ

| লক্ষণ | কেন হয় |
|--------|---------|
| USB থাকলে চালু, USB কেটলে **বন্ধ** | ESP32 **শুধু USB 5V** দিয়ে চলছে; **18650 → ESP32 VIN/BAT** যুক্ত নেই বা খারাপ |
| সবুজ/লাল LED **জ্বলে না** (USB ছাড়া) | LED অনেক বোর্ডে **শুধু চার্জার IC**-এর; USB না থাকলে **চার্জ LED বন্ধ** স্বাভাবিক |
| USB ছাড়া LED না জ্বলা কিন্তু বোর্ড চলে | কিছু PCB-তে **ব্যাটারি স্ট্যাটাস LED নেই** — LED = চার্জ ইন্ডিকেটর |

## চেকলিস্ট (STA)

1. **18650** সঠিক পোলারিটিতে বসানো, ভোল্টেজ ~3.7V+  
2. **ব্যাটারি → PCB** (BAT+, BAT−) তার কাটা/লুজ নেই  
3. ESP32 **3.3V** (USB ছাড়া): মাল্টিমিটার — ব্যাটারি থাকলে ~3.3V আছে কিনা  
4. **MAX98357 VIN** → VBAT; USB ছাড়া **অ্যাম্প**-ও ব্যাটারি চাই  
5. **HaLow মডিউল** আলাদা পাওয়ার খায় কিনা  
6. প্রটেকশন PCB **ট্রিপ** — ব্যাটারি খালি/শর্ট হলে সাপ্লাই কেটে যায়  

## USB vs ব্যাটারি

```
USB 5V ──► [LDO] ──► ESP32 3.3V     (PC তে টেস্ট সাধারণত এটাই)
18650 ──► [boost/LDO] ──► ESP32 + VBAT ──► স্পিকার/রেডিও
```

USB তুললে **দ্বিতীয় লাইন** কাজ না করলে ESP **অফ**।

## কোডে কী আছে

- `GPIO 3` = ব্যাটারি ADC (মাপ, LED নয়) — `shared/battery_config.h`  
- LED চালনা **এই প্রজেক্টে GPIO থেকে নেই** (আলাদা চার্জার চিপ)

## টেস্ট

1. ব্যাটারি ফুল চার্জ, USB **কাচ্চা না** (শুধু 5V দিয়ে) বা USB খুলে  
2. ESP32 **3.3V পিন** vs GND  
3. 3.3V **নেই** → হার্ডওয়্যার মেকানিক / ব্যাটারি মডিউল  
4. 3.3V **আছে** কিন্তু “অফ” — ব্রাউনআউট, খারাপ ব্যাটারি, শর্ট
